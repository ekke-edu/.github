# 🇭🇺 Magyar verzió

### 🙋‍♀️ Rólunk
Üdvözlünk az **Eszterházy Károly Katolikus Egyetem (EKKE) Software Engineering** GitHub szervezetében! 👋 
Ez a felület a Programtervező informatikus képzés szoftverfejlesztéshez, programozáshoz és adatbázisokhoz kapcsolódó kurzusainak központi tárhelye. Itt találjátok a feladatok kiinduló kódjait, a segédanyagokat és a projekt-sablonokat.

### 💻 Munkafolyamat és feladatok megoldása (Forking)
A hallgatók a szervezet repository-jaihoz alapértelmezetten **csak olvasási (Read) jogosultsággal** rendelkeznek. A feladatok kidolgozásához a következő munkafolyamatot kell követni:

1. **Fork:** Készíts egy másolatot (Fork) a kiadott repository-ról a saját GitHub fiókodba.
2. **Clone:** Klónozd le a saját, forkolt repository-dat a helyi gépedre vagy a fejlesztői környezetedbe (pl. DevContainer).
3. **Commit & Push:** A munkádat a saját repository-dba mentsd el.
4. **Kérjük, NE küldj hozzáférési kérelmet (Request Write Access)** a központi repókhoz, mert azokat nem fogjuk jóváhagyni.

### 🔐 Jogosultságok és Csapatmunka
A nagyobb volumenű, csoportos projektek esetén szükség lesz közös repository-kra és írási (Write) jogokra. 
* Ezeket a jogosultságokat és a GitHub Teams beállításokat **az oktatók fogják kiosztani** a félév során.
* Neked ezzel kapcsolatban nincs előzetes teendőd, a kurzus oktatója jelezni fogja, amint a csapatod megkapta a szükséges hozzáféréseket.

# 🇬🇧 English version

### 🙋‍♀️ About Us
Welcome to the GitHub organization of **Software Engineering at Eszterházy Károly Catholic University (EKKE)**! 👋
This space serves as the central hub for Computer Science students attending courses in software development, programming, and databases. Here you will find starter codes, course materials, and project templates.

### 💻 Workflow and Assignments (Forking)
By default, all students have **Read-only access** to the repositories within this organization. To work on your assignments, you must follow this workflow:

1. **Fork:** Create a copy (Fork) of the provided assignment repository to your personal GitHub account.
2. **Clone:** Clone your forked repository to your local machine or development environment (e.g., DevContainer).
3. **Commit & Push:** Save and push your work to your own forked repository.
4. **Please DO NOT send "Request Write Access" notifications** for the central repositories, as they will be declined.

### 🔐 Permissions and Teamwork
For larger, collaborative group projects, you will need shared repositories and Write permissions.
* These permissions and GitHub Teams will be **assigned and configured by your instructors** during the semester.
* You do not need to request access manually; your course instructor will notify you once your team's environment is set up.
